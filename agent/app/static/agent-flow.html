下图是生产 `react_v1` 架构参考，不冒充上方 DebugTurn 的实际阶段记录。

权威控制路径橙：Validator→Policy 修正循环　紫：两类独立暂停边界　蓝：权威状态

竖向可读版

  1. Web Request绑定 session，区分 fresh / clarification resume / paused resume。
  2. TaskManager → TaskState → ContextPack选择任务、写 revision，并投影当前节点可见上下文。
  3. Entry → ReAct Policy恢复权威状态；resolver 优先，Decision LLM 每轮最多 2 次。
  4. Executor → Validator执行一个服务端动作合同，再核验证据、范围和约束。
  5. 修正循环Validator 需要修正时回到 ReAct Policy；不是回到 Entry。
  6. 澄清边界Policy ask_user → interrupt()；用户答案在同一 thread 继续。
  7. 操作员暂停边界任一 durable 节点前检查；安全节点完成后，以 receipt + checkpoint 恢复待执行节点。
  8. Answer Buffer → Atomic Finalize → Publish验证后的回答先缓冲，再原子提交 TaskState + Outbox，最后发布或重放。
  9. 持久化边界TaskState CAS、Graph Checkpoint、Tool Inbox、Final Outbox 分责保存。
