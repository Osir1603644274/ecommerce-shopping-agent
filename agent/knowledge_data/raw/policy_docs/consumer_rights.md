# 本地生活消费者权益说明

> 本文是基于公开法规整理的项目知识库摘要，用于本地生活智能体演示；不构成正式法律意见。具体规则以官方原文和专业意见为准。

## 消费者有权了解重要服务信息 {#service-information}

本地生活服务涉及价格、服务内容、退款方式、押金、预付款等重要信息时，商户和平台应当尽量清楚展示。重要限制条件不应以默认勾选、隐藏提示等方式让消费者在不知情的情况下承担不利后果。

适合回答的问题：

- 商户是否应该提前说明退款条件？
- 平台是否应该展示重要消费限制？
- 用户下单前应该看到哪些关键信息？

## 退款、押金和预付款应当有明确规则 {#refund-deposit-prepaid}

如果商户或平台收取押金，应当事先约定退还方式、程序和时限，不能设置不合理退还条件。预付款类服务应当明确服务内容、价格、退款方式和违约责任；如果商户无法按约提供服务，消费者可以要求继续履行或退还未消费余额。

适合回答的问题：

- 押金迟迟不退怎么办？
- 充值卡或预付费服务没用完能不能退？
- 商户停业后预付款怎么处理？

## 网络消费的退货或退款限制应当显著提示 {#refund-restrictions}

对于网络方式销售的商品或服务，商户不能擅自扩大不适用无理由退货的范围。若某些商品或服务不适用无理由退货，应当用显著方式标注，并在购买时提示消费者确认，不能默认消费者同意。

适合回答的问题：

- 不支持退款的限制需要提前说明吗？
- 商户能不能默认用户同意不退款？
- 什么情况下用户可以要求平台协助处理退款争议？

## 消费者投诉和争议处理应当有通道 {#complaint-dispute}

当消费者认为商户服务、退款、押金或预付款处理存在问题时，平台应当提供清晰的投诉或争议处理入口。平台在处理争议时，应当尽量基于订单、服务记录、规则说明和双方证据进行判断。

适合回答的问题：

- 用户对服务不满意可以怎么处理？
- 平台应该如何处理消费争议？
- 投诉时需要准备哪些信息？
