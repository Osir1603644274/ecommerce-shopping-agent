## 用户批准的边界

- 一套 React 前端、一套 Python Agent、一套 Java 模块化单体；Java 仍为交易权威。
- 439 款二手手机为新在售目录；旧目录退出新导购但保留历史商品、账号、订单、支付与收藏。
- 使用独立本地模拟售价及每款首次 10 件库存；不修改原始快照价格，不把合成价格标记为 verified。
- 手机知识库保留。聊天为主、橙色电商风格，收藏/订单为辅助入口。
- 取消、退款先预览再确认；履约依据真实记录。支付和仓库仅本地模拟。

测试创建了隔离账号、订单与模拟支付/退款记录并保留；不清表、不回填消耗的库存。

启动器不自动创建数据库/重建镜像/运行迁移；Docker Desktop 启动后，`start` 会恢复已有依赖、Java 与入口。
