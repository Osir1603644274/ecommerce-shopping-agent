# 首批二十个贯穿场景合同

状态：设计预期，尚非执行结果或人工黄金标签。由业务规则测试和端到端 runner 分别落实。

| ID | 初始条件和动作 | 必须观察到的终点/不变量 |
|---|---|---|
| CS01 | 本人已支付从未出库，退款一件 | 旧退款路径；匹配回执后减退款余额、恢复对应库存 |
| CS02 | 退款预览后仓库取得出库 claim | 提交拒绝或回查；不能按未出库恢复库存 |
| CS03 | 本人完成收货，期限内仅退款 | 审核通过仍待渠道回执；无退货库存增加 |
| CS04 | 仅退款审核拒绝 | 有理由、可关联争议工单；无资金变化 |
| CS05 | 七天截止恰好提交与超出一纳秒 | 前者可受理，后者不能自动办理 |
| CS06 | 历史订单无收货时间 | 核实待办，不从更新时间推导签收 |
| CS07 | 退货退款，匹配商品数量，验收可售 | 渠道确认退款；验收数量仅入库一次 |
| CS08 | 质量问题退货，准予退款但不可售 | 退款可完成；残次品隔离，可售量不增加 |
| CS09 | 退回商品身份或数量不符 | NEEDS_REVIEW；不能自动退款 |
| CS10 | 同规格换货验收通过且有库存 | 验收后占库、补发、签收；不再次收费 |
| CS11 | 不同规格换货 | 拒绝自动换货，不擅自选其他商品 |
| CS12 | 换货缺货，用户选择等待 | 等待状态保留原诉求；补货后可继续 |
| CS13 | 换货缺货，用户确认改退款 | 复用退货验收，原补发不能再执行 |
| CS14 | 用户请求查询其他人订单/售后 | 无信息泄露、无业务写入 |
| CS15 | 同幂等键重复提交/不同参数提交 | 原结果重放/参数冲突；无第二份副作用 |
| CS16 | 不同键并发退款与换货同一订单 | 最多一笔活动操作，数量金额不超限 |
| CS17 | 审核中撤销；寄回后请求撤销 | 前者释放占用；后者核实，不吞掉在途货物 |
| CS18 | 写入成功但响应丢失，进程重启 | 同命令回查恢复；不重复退款或补发 |
| CS19 | 多订单指代，修改申请数量后用旧确认卡 | 必要澄清；旧版本确认不执行 |
| CS20 | 客服模型/知识服务故障与渠道回执延迟 | 表单查询可用；未知结果不报成功；记录耗时与缺失用量 |

所有场景关联 case/session/task/request/tool/order/afterSale/event/receipt。
禁止用本合同、单元测试数量或模拟器自身的 success 字段代替独立数据库及回执评分。
