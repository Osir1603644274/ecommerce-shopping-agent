# 统一商品路由实施记录（2026-09-22）

状态：`IMPLEMENTED_LIVE_VERIFIED`

## 最终边界

| 用户请求 | 路由 | 执行链路 |
|---|---|---|
| 任意品类的商品搜索或条件修改，包括手机 | `catalog` | `catalog_workspace_v1` |
| 针对当前商品卡片的追问 | `product` | 同一商品工作区的只读问答 |
| 订单、支付、退款、物流与售后 | `business` | 原有持久化业务 Agent |

路由 Schema 已删除 `phone`。手机不再拥有独立搜索入口；品类、品牌、型号、预算等都作为统一需求数据传入目录检索。目录证据与交易权威仍分离：检索命中不能自行制造价格、库存或购买资格。

## 实施内容

- 删除路由提示词和运行时中的 `phone` 分支，新增通用 `business` 边界。
- 澄清恢复、商品追问和配件换类目均使用通用商品语义。
- 统一界面文案与示例，同时展示手机和非手机需求。
- 统一目录模式启动时跳过旧 439 手机向量缓存预热；旧兼容代码不再参与 5173 商品检索。
- 新增路由、工作流、业务隔离与启动预热回归测试。
