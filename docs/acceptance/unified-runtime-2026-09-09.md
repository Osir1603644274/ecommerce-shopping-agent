# 日常 Agent 运行入口统一（2026-09-09）

结论：本机功能验收通过。日常入口为 http://127.0.0.1:5173/，固定调用
8000 Agent/BFF，再由 Agent 调用 Docker 网络内的 `backend:8080`（宿主机 8080）。
这是一套 Agent 同时提供导购和交易接口，不把 Java 的交易权限或事务移交给模型。

## 审计与用户决定

- 旧本机 18000 Agent 实际连接 18083 Java，目录版本
  `used-phone-runtime-439-v1-09807c773ce6`，439 款商品；独立 MySQL、Redis、Elasticsearch 与知识库配置。
- 主交易环境 8000 Agent 连接 `backend:8080`，目录版本 `09807c7`，1500 款商品。
  两个 `/api/products?limit=1500` 目录 ID 集合交集为 0；例如主环境的可交易商品 2278548 在旧 439 目录返回 404。
- 因此没有把旧导购的合成参考价当成主交易价格，也没有复制商品、账户、历史会话或补充库存。
- 用户明确选择：**先用现有可交易商品完成闭环，439 款目录保留不动**。
  本次不宣称已迁移 439 目录、旧独立商品知识库或两个环境的聊天历史。

## 实施

- 新增 `scripts/unified-commerce.ps1 start|health|stop`。复用现有主环境容器、卷和前端依赖；不 build、不初始化数据库。
- 启动前核对 Agent 的 Java 地址、交易与模拟支付开关，Java 模拟器开关和宿主机端口。
  先启动主环境依赖、等待 Java readiness，再启动 Agent 和隐藏 Vite。
- 启动 Vite 时明确绑定 `COMMERCE_BFF_URL=http://127.0.0.1:8000`；5173 被非本脚本进程占用时拒绝操作。
- 前端 PID 记录创建时间，防止 PID 复用时误杀其他程序。`stop` 只停本脚本拥有的前端，保留共享后端及数据库。
- `health` 同时检查前端所有权与监听、网页 HTTP、代理后交易能力、Agent 实际 Java 地址、Java readiness。
- 真实闭环通过后停止旧 18000 的 uvicorn 子进程 43024（父进程 54568，创建时间 UTC 02:40:55，命令行与监听已核对）。
  旧目录、容器、卷、运行日志和启动脚本均保留；共享 18791 知识库服务未停止。旧 Agent 可按原脚本人工恢复，不是删除功能。
- Playwright 新增 `PW_BASE_URL`，指定时不再创建另一台 5180 Vite。真实验收直接访问 5173；模拟回归仍使用隔离的 5180。
- README 和 frontend README 更新默认入口及恢复命令。没有修改导购算法、Java 业务逻辑或主环境既有检索模式（仍为 hybrid）。

## 验证

- 前端 production build 通过；Vitest 4 个文件、22 项测试通过。
- 模拟浏览器：订单 17 + 统一购物 6 = 23 项通过；此类测试使用 HTTP 拦截，不冒充数据库验收。
- `PW_BASE_URL=http://127.0.0.1:5173` 的真实购物用例通过：搜索得到商品、游客衔接登录、收藏重选、数量 2、预览后重登、确认下单、模拟丢响应后的原键恢复、明确确认支付、本地模拟成功、本人订单回查、刷新恢复、退出后清空私有数据。
- 同一真实入口的账户安全用例通过：隔离 A/B 账户、他人订单/支付/确认访问被拒绝、请求 20 件库存不足被拒绝、共享 Cookie 的旧标签页被拒绝；只创建测试账号与收藏，不新增订单。
- 启动脚本实际验证 `start`、重复 `start`、`stop → start`、`health`。最后 `legacy18000Running=false`。
- 开发期脚本曾遇到 PowerShell 函数名覆盖 docker 命令、JSON 时间反序列化比较问题；分别改为调用 docker.exe 和规范化 DateTime 后，上述运行验证通过。
- 本轮没有新增独立 SDK 模型调用证据；真实搜索 HTTP 成功不等同于推荐事实质量或模型评测通过。

## 使用与边界

```powershell
pwsh -File F:\agent\scripts\unified-commerce.ps1 start
pwsh -File F:\agent\scripts\unified-commerce.ps1 health
```

只访问 http://127.0.0.1:5173/；搜索可从“推荐2000元以内的二手手机”开始。
只有主环境里已有有效交易价格和可用库存的商品能下单。模拟付款前仍需明确确认。
本机需 Docker Desktop 正常运行；不是开机自启、首次安装脚本、生产部署或真实支付平台。
缺失容器、功能开关不符时脚本明确报错，不会悄悄重建共享环境。
