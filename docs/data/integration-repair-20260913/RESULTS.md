## 自动修复的边界

质量规则只添加可解释的标记，没有将“短标题”“URL”“补差价”命中整批删除，也没有将 UNKNOWN 转为 0 分。比如“5号电池”“7号篮球”不因为数字＋号被当作地址。损坏字符的原意未知，不猜测恢复。

同标题聚合保留每个成员的来源、ID、原名次与原分数，各成员详情仍单独保留卖家。历史145条纯CE排名的1,450个位置可展示为1,356组；减少的是94个同标题重复展示位，**不是相关性提高94次，也不是确认94件重复SKU**。本轮没有为了补足10个不同标题而从后续名次取新商品。

手机视图的 source_claim、known、CLEAR 都不是实物鉴定。只对明确单型号的标题允许下一层考虑型号资料；资料引用仍需来源核验，不能将标准机规格当作翻新/改装实物的保证。

## 尚不能靠程序补出的事实

| 待证据项 | 本轮处理 | 真正需要的外部信息 |
|---|---|---|
| 180 件历史价格的币种、单位、时效与 SKU | 不换算、不用于真实预算；保留原始数值与模拟价两层 | 原始数据字段定义或作者说明；若声称当前报价还需当前商品记录 |
| 187 手机派生身份，以及其他语料的歧义映射 | 保留本地身份/候选关系，禁止自动补属性 | 原始 ID 对照或可核对的原商品记录；主观“看着相同”不够 |
| 品牌矛盾、损坏标题、来源缺失属性 | 标明 source_claim/unknown/质量标记 | 能对应同一商品的可信原记录；不要求用户逐条给数百万商品打分 |
| 数据再分发许可信息不一致/缺失 | 本地来源清单保留；没有发布数据 | 对应版本的数据许可说明或作者确认 |

它们不会阻断普通文本检索，但限制哪些事实可被声称。当前无需你逐条审批已实现的工程修复。若要消除这些未知，需要资料，不能通过一次“批准”创造事实。
