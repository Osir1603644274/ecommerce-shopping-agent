- 这次完成的是电商数据版本清理与重点能力 benchmark 登记，不是清空全仓所有 evaluation、回归 fixture、下载缓存或跨盘实验。
- 旧路径仍可见是有意的兼容措施；真正日常入口已集中。恢复迁移前先查清单，不覆盖后来产生的内容；操作联接时不能递归删除目标。
